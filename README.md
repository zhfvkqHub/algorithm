# Algorithm

코딩 테스트 문제 풀이를 정리하는 개인 알고리즘 프로젝트입니다.  
풀이 시기와 접근 방식에 따라 버전을 구분하여 관리합니다.

---

## 버전 정보

### v1 (2022–2023)
- 2022년부터 2023년까지 풀이한 코딩 테스트 문제 모음

### v2 (2026~)
- 2026년부터 새롭게 시작한 코딩 테스트 풀이 모음
